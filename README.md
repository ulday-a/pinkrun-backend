# Pink Run — бэкенд

Обрабатывает: регистрацию участников, вход в кабинет по SMS-коду (SMSC.kz),
список участников, отмену регистрации, оплату через BCC Pay.

## Структура

```
server.js           — точка входа
db.js                — подключение к Postgres, создание таблиц
routes/register.js   — регистрация, список участников, отмена
routes/auth.js        — отправка/проверка SMS-кода
routes/payment.js     — интеграция с BCC Pay (частично заглушка, см. ниже)
.env.example          — какие переменные окружения нужны
```

## Развёртывание на Render (пошагово)

1. **Выложите этот код в GitHub-репозиторий** (создайте новый репозиторий, загрузите
   в него содержимое папки `pinkrun-backend`).

2. **База данных.** На [render.com](https://render.com) создайте бесплатный
   PostgreSQL (New → PostgreSQL). После создания скопируйте строку
   `Internal Database URL` — она понадобится на следующем шаге.
   *(Альтернатива: [neon.tech](https://neon.tech) — тоже есть постоянный бесплатный Postgres.)*

3. **Веб-сервис.** На Render: New → Web Service → подключите ваш GitHub-репозиторий.
   - Build Command: `npm install`
   - Start Command: `npm start`

4. **Переменные окружения.** В настройках сервиса (Environment) добавьте:
   - `DATABASE_URL` — строка из шага 2
   - `ALLOWED_ORIGIN` — `https://pinkrun.kz`
   - `SMSC_LOGIN`, `SMSC_PASSWORD` — данные вашего аккаунта на smsc.kz
   - `BCC_MERCHANT_ID`, `BCC_API_KEY`, `BCC_API_SECRET`, `BCC_API_BASE_URL` — выдаст
     банк после подключения через developer.bcc.kz (пока можно оставить пустыми —
     сайт будет работать, но оплата вернёт понятную ошибку вместо запуска платежа)

5. Нажмите **Deploy**. Render соберёт и запустит сервис, выдаст адрес вида
   `https://pinkrun-backend.onrender.com`.

6. Откройте этот адрес в браузере — должно вернуться `{"status":"ok", ...}`.
   Значит, сервер запущен и подключился к базе.

## Что дальше

После того как бэкенд задеплоен и доступен по адресу — нужно обновить
`tilda-script.js` (наш фронтенд-код), чтобы он реально отправлял запросы на этот
адрес вместо демонстрационных JS-переходов между экранами. Это следующий шаг,
который я подготовлю отдельно, когда у вас будет готовый адрес бэкенда.

## Про BCC Pay

Точная структура запросов в `routes/payment.js` — примерная, по типовой схеме
эквайринговых API (создание платежа → редирект клиента на оплату → webhook с
результатом). Как только получите официальную документацию и ключи от банка
(через developer.bcc.kz) — пришлите мне, и я поправлю запросы под реальный
формат BCC.

## Про SMSC.kz

Интеграция уже рабочая по официальному HTTP API SMSC.kz (`smsc.kz/sys/send.php`).
Нужно только завести аккаунт на [smsc.kz](https://smsc.kz), пополнить баланс и
указать логин/пароль в переменных окружения.
